# パスワード生成

使う記号を自由に指定できるパスワード生成サイトです。PC とスマホのどちらでも使えます。

**サイト：** https://stipruriju.github.io/password-generator/

パスワードはお使いの端末の中だけで作られ、送信・保存されません。

## 特徴

- **使う記号を貼り付けで指定**
  - サイトごとに使える記号が違っても、その記号だけでパスワードを作れます。
  - 全角で貼り付けても半角に直します。
  - 記号以外の文字は使いません。
- **記号の数を指定**：記号を何文字入れるか、下限と上限を決められます。空欄にすると指定しません。
- **使う文字を選択**：小文字・大文字・数字・記号を、それぞれ使うかどうか切り替えられます。
- **オプション**
  - 各種類の文字を1文字以上含める
  - 紛らわしい文字（`0 O o 1 l I |`）を使わない
  - 先頭を英字にする
  - 同じ文字を連続させない（`aa` `11` `##` などを作らない）
- **長さ**：4〜64文字
- **コピー**：パスワードをタップ（クリック）するとコピーされます。
- **強さの表示**：パスワードの強さをビット数で示します。
- **ライト／ダーク**
  - 最初は端末の設定に合わせて表示します。
  - 右上のボタンで切り替えると、その選択を次回も使います。
- **画面に合わせて表示**：PC でもスマホでも、1画面に収まるよう文字の大きさを自動で調整します。
- **オフラインでも使える**
  - 一度開くと、ネットにつながっていなくても使えます。
  - ホーム画面に追加することもできます。

## 安全性

- パスワードは、ブラウザの暗号用の乱数（`crypto.getRandomValues`）だけを使って作ります。
- 偏りが出ないように、範囲外の値を捨てて引き直しています。条件を付けても、条件を満たすパスワードはどれも同じ確率で出ます。
- 外部との通信は、ページの設定（Content-Security-Policy）で禁止しています。
- 端末の中に保存するのは、次の設定だけです（`localStorage`）。パスワードそのものは保存しません。
  - 長さ
  - 使う記号
  - スイッチのオン／オフ
  - ライト／ダークの選択

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | サイト本体（HTML・CSS・JavaScript を1ファイルにまとめたもの） |
| `sw.js` | オフラインで使えるよう、ファイルを端末に保存する仕組み（Service Worker） |
| `manifest.webmanifest`<br>`icon.svg`<br>`icon-192.png`<br>`icon-512.png` | ホーム画面に追加するための設定とアイコン |
| `fonts/` | スマホ用のフォント（ページで使う文字だけに絞ったもの） |

## 更新するときの注意

- **`sw.js` の `VERSION` を上げる**
  - ファイルを変えたら、`VERSION` を必ず上げてください（例：`'v8'` → `'v9'`）。
  - 上げないと、一度開いた端末に古いファイルが残ることがあります。
- **画面の日本語を変えたら、フォントのファイルを作り直す**
  - `fonts/noto.woff2` には、今のページで使っている文字しか入っていません。
  - 新しい漢字やかなを増やしたときは、作り直してください。作り直さないと、その文字だけ別のフォントで表示されます。
